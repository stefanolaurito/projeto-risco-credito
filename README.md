
# Projeto de Risco de Crédito

Projeto de Machine Learning para análise e previsão de risco de crédito,
desenvolvido como trabalho final do curso SCTEC Aperfeiçoar -
Integração de IA com Dados.

## Objetivo

Construir um modelo capaz de identificar clientes com maior probabilidade
de inadimplência, apoiando a análise de concessão de crédito.
